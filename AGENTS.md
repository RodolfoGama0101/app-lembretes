# Instruções do projeto

- Ao concluir cada tarefa que alterar arquivos, crie um commit Git apenas com as alterações feitas nessa tarefa.
- Use Conventional Commits nas mensagens: `tipo(escopo opcional): descrição` (por exemplo, `feat(reminders): add unscheduled reminders` ou `fix(ui): align add button right`).
- Preserve alterações preexistentes ou de outras pessoas; não as inclua no commit.
- Antes de finalizar, execute as verificações pertinentes e informe o hash do commit. Se a tarefa não alterar arquivos, informe que não há alterações para commitar.
